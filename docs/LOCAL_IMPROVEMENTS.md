# 本地改进计划

日期：2026-10-04。基于上游 `336fe39` / v6.0，本轮保留单文件 HTML、离线运行和原作者署名。

## 目标与范围

1. 统一清洗聊天、记忆和打印页中的 Markdown HTML，修正打印页动态文本转义。
2. Markdown 单篇与批量导出保留源数据已有的完整工具结果、思考和附件提取文本。
3. PDF 保留完整思考内容，提供可选的工具记录和附件正文；打印页禁止脚本。
4. 为导出完整性、安全渲染和新旧数据导入增加可重复执行的网页核心回归测试。

保留原有导入与档案存储方式。本轮不改视觉设计、不拆分为框架项目、不增加服务器或联网依赖。阅读副本不替代原始 ZIP/JSON；无法恢复源数据中不存在的附件或消息。

## 实施顺序

- [x] 安全渲染：通过 `build/build.py` 内联 DOMPurify 3.4.16；统一 Markdown 渲染入口；清洗失败显示纯文本。
- [x] 完整导出：移除 Markdown 字符截断；修正 PDF 思考截断并增加导出选项和工具记录。
- [x] 验证：合成数据回归测试，覆盖截断边界、危险 HTML、公式、代码块、新旧导入与批量导出。
- [x] 浏览器检查：本地 `file://`、离线零外部请求、PDF 预览、深色与窄屏。
- [x] 文档：同步中英文说明和测试命令，记录实际验证结果与限制。

## 验收标准

- 单篇和批量 Markdown 均能找到长工具结果、附件文本、思考文本末尾的验证标记。
- PDF 默认显示完整思考；勾选后显示工具输入、结果和附件提取正文，长文本可换行打印。
- 聊天、记忆、打印路径不会执行导入内容中的事件处理器或危险链接；清洗器不可用时不显示未经清洗的 HTML。
- 代码块、表格、折叠内容与数学公式仍可阅读；新旧合成导出包均可导入。
- 交付仍为一个双击可打开的 HTML 文件，所有运行依赖内联。

## 实施记录

### 完成情况

本地版本为 `v6.0.1-local`，不是上游正式发布。核心仍为 `claude_viewer.html`，约 1 MB。

- `safeMarkdown()` 对聊天和记忆采用相同的 HTML 白名单，去除事件属性、导入的控件标识和样式类，禁止外部图片，限制链接协议。缺失清洗器或清洗出错时显示转义后的原文。
- PDF 使用同一入口，公式渲染后再次清洗；转义思考摘要、工具名称和附件文本；打印页声明 `script-src 'none'`。
- Markdown 单篇与批量使用同一完整导出函数。PDF 默认包含完整思考，工具与附件正文默认不勾选。
- 修正 `document.open()` 清除加载监听器造成的打印时序问题；打印前展开折叠内容、等待字体，并增加纸张页边距和适于打印的代码块颜色。
- 依赖通过构建脚本内联；缓存文件名包含库名与版本路径。原有 JSZip、marked、KaTeX、字体及样式与上游逐字比较一致。
